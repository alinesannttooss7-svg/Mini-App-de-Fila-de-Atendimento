 # Mini App de Fila de Atendimento

Projeto desenvolvido como atividade da disciplina de ADS.

O sistema foi desenvolvido utilizando Python, Flask e SQLite.

## Funcionalidades

- Cadastro de clientes;
- Visualização da fila;
- Sistema de fila de atendimento;
- Chamar próximo cliente;
- Status Aguardando;
- Status Em Atendimento;
- Status Concluído;
- Cancelamento de atendimento;
- Prioridade Normal e Preferencial;
- Histórico de atendimentos;
- Atualização automática da fila.

## Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML
- CSS
